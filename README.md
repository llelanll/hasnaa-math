# رياضيات خامس مع الأستاذة حسناء

موقع عربي تفاعلي لطالبات الصف الخامس الابتدائي، مبني باستخدام JavaScript وVite، ومتوافق مع الجوال والكمبيوتر.

## المحتوى
- دروس في مضاعفات الأعداد، والضرب في ١٠ و١٠٠، والأنماط المتضاعفة.
- لعبة أنماط الضرب: ١٠ أسئلة مع تصحيح فوري وشرح لكل إجابة.
- اختبار قصير وتحدٍ فردي يستخدمان أسئلة أنماط الضرب نفسها.
- ١٠ نقاط لكل إجابة صحيحة، محفوظة في متصفح الجهاز باستخدام localStorage.
- نتيجة من ١٠، وعدد الإجابات الصحيحة، وتشجيع، وإعادة المحاولة.
- نجوم الجولة: ٣ لدرجة ٨ فأكثر، ٢ لدرجة ٥–٧، ١ لدرجة ١–٤، و٠ لدرجة صفر.

## التشغيل
يتطلب Node.js 20.19+ أو 22.12+، وقد تم التحقق باستخدام Node.js 24.

```sh
cd /workspace/hasnaa-math
npm ci --cache /tmp/hasnaa-npm-cache
npm run dev -- --port 5173
```

## التحقق والبناء
```sh
npm run build
npm test
```
تتطلب اختبارات المتصفح تشغيل خادم التطوير على المنفذ 5173 ووجود Chromium في `/usr/bin/chromium`؛ يمكن تحديد مسار آخر بواسطة `CHROMIUM_PATH`.

```sh
npm run preview -- --port 4173
```

الناتج في `dist/` قابل للنشر على أي استضافة للمواقع الثابتة. الخطوط مضمنة محليًا ولا يحتاج الموقع إلى خدمات خارجية أو مفاتيح سرية. النقاط خاصة بمتصفح الجهاز، ولا توجد حسابات أو لوحة ترتيب بين الطالبات.

## النشر على GitHub Pages

المشروع مضبوط في `vite.config.js` للمسار `/hasnaa-math/`. يعيد Vite كتابة مسارات JavaScript وCSS والخطوط في نسخة الإنتاج لتعمل تحت هذا المسار. التنقل داخل الموقع لا يتطلب إعادة توجيه من الخادم.

1. ارفعي ملفات المشروع إلى فرع `main` في مستودع `llelanll/hasnaa-math`، بما فيها مجلد `.github/workflows` وملف `package-lock.json`. لا ترفعي `node_modules` أو `dist`.
2. في GitHub افتحي المستودع ثم **Settings → Pages**.
3. تحت **Build and deployment → Source** اختاري **GitHub Actions**.
4. افتحي **Actions → Deploy to GitHub Pages → Run workflow**، اختاري `main`، ثم اضغطي **Run workflow**. لاحقًا سيعمل النشر تلقائيًا عند كل دفع إلى `main`.
5. انتظري نجاح مرحلتي `build` و`deploy`. سيظهر رابط الموقع في **Settings → Pages** وفي نتيجة النشر.

العنوان المتوقع بعد نجاح النشر: `https://llelanll.github.io/hasnaa-math/`.
إذا كان المستودع خاصًا، يعتمد توفر GitHub Pages على خطة GitHub؛ سيظهر ذلك في صفحة Pages. إذا تغير اسم المستودع أو استُخدم نطاق مخصص، عدّلي `base` في `vite.config.js` وفق المسار الجديد (للنطاق المخصص عادة `/`).

### اختبار نسخة النشر

```sh
npm run build
npm run preview -- --port 4173
TEST_BASE_URL=http://127.0.0.1:4173/hasnaa-math/ npm test
```

خادم Python يجب أن يقدم الموقع تحت مجلد `hasnaa-math` أيضًا؛ تقديم `dist` مباشرة على جذر الخادم لا يطابق إعداد GitHub Pages الجديد.

## نموذج درس أنماط الضرب

افتحي `#multiplication-patterns` أو اختاري «ابدئي الدرس» من صفحة الدروس.
يتضمن أهدافًا وتهيئة بصرية وشرح القيمة المنزلية وثلاثة أمثلة أصلية وأربعة تدريبات متدرجة، ثم اللعبة الحالية ذات عشرة أسئلة واختبارًا مستقلًا من خمسة أسئلة مع تحليل المهارات.
يمنح كل تدريب عشر نقاط مرة واحدة في الزيارة، والاختبار عشر نقاط لكل إجابة صحيحة عند التسليم، مع منع تكرار نقاط التسليم. يمكن إعادة الاختبار في محاولة جديدة. النقاط محفوظة محليًا؛ إجابات الدرس وتقدمه تبقى أثناء التنقل داخل الزيارة ولا تُحفظ بعد إعادة تحميل الصفحة.
المرجع المفاهيمي: الفصل الثالث، الدرس الأول «أنماط الضرب»، من الكتاب المرفق. الشرح والأمثلة والتدريب والاختبار الجديد مؤلفة للموقع. أسئلة اللعبة القديمة محفوظة دون تغيير.
اختبارات المتصفح تشمل عروض ٣٢٠ و٣٩٠ و١٢٨٠ بكسل، التهيئة والتلميحات والتصحيح والنقاط واللعبة ومراجعة المهارات وإعادة الاختبار، إضافة إلى اختبارات الصفحات واللعبة السابقة.

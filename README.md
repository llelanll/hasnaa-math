# رياضيات خامس مع الأستاذة حسناء

موقع عربي تفاعلي لطالبات الصف الخامس الابتدائي، مبني باستخدام JavaScript وVite، ومتوافق مع الجوال والكمبيوتر.

## المحتوى

- المنهج كاملًا: ١٢ فصلًا، ٨١ درسًا أساسيًا ومعمل إثرائي تفاعلي، و٨٢ اختبارًا مستقلًا من ٥ أسئلة.
- [التقرير والحصر وروابط الفصول](docs/curriculum-report.md) · [الحصر الآلي](docs/curriculum-inventory.json).
- دروس بتمثيلات مناسبة لكل مهارة، محملة عند الحاجة، وفهرس للفصول ولوحة تقدم عامة.
- دروس في مضاعفات الأعداد، والضرب في ١٠ و١٠٠، والأنماط المتضاعفة.
- لعبة أنماط الضرب: ١٠ أسئلة مع تصحيح فوري وشرح لكل إجابة.
- اختبار قصير وتحدٍ فردي يستخدمان أسئلة أنماط الضرب نفسها.
- ١٠ نقاط لمكافأة السؤال الصحيح مرة واحدة على الجهاز، محفوظة باستخدام localStorage؛ إعادة اللعب أو الاختبار لا تكرر مكافأة السؤال نفسه.
- نتيجة من ١٠، وعدد الإجابات الصحيحة، وتشجيع، وإعادة المحاولة.
- نجوم الجولة: ٣ لدرجة ٨ فأكثر، ٢ لدرجة ٥–٧، ١ لدرجة ١–٤، و٠ لدرجة صفر.

## التشغيل
يتطلب Node.js 20.19+ أو 22.12+، وقد تم التحقق باستخدام Node.js 24.

```sh
cd /workspace/hasnaa-math
npm ci --cache /tmp/hasnaa-npm-cache
npm run dev -- --port 5173
```

## التحقق والبناء
```sh
npm run build
npm test
```
تتطلب اختبارات المتصفح خادمًا للموقع. تستخدم افتراضيًا خادم التطوير على 5173، ويمكن تشغيلها على نسخة الإنتاج بتحديد `TEST_BASE_URL=http://127.0.0.1:4173/hasnaa-math/`. يُستخدم Chromium المحلي إن وجد، أو متصفح Playwright المثبت؛ يمكن تحديد مسار صريح بواسطة `CHROMIUM_PATH`. يشغّل `npm test` ملفين من الاختبارات بالتوازي، وتشغّل GitHub Actions المجموعة كاملة قبل النشر.

```sh
npm run preview -- --port 4173
```

الناتج في `dist/` قابل للنشر على أي استضافة للمواقع الثابتة. الخطوط مضمنة محليًا ولا يحتاج الموقع إلى خدمات خارجية أو مفاتيح سرية. النقاط خاصة بمتصفح الجهاز، ولا توجد حسابات أو لوحة ترتيب بين الطالبات.

## النشر على GitHub Pages

المشروع مضبوط في `vite.config.js` للمسار `/hasnaa-math/`. يعيد Vite كتابة مسارات JavaScript وCSS والخطوط في نسخة الإنتاج لتعمل تحت هذا المسار. التنقل داخل الموقع لا يتطلب إعادة توجيه من الخادم.

1. ارفعي ملفات المشروع إلى فرع `main` في مستودع `llelanll/hasnaa-math`، بما فيها مجلد `.github/workflows` وملف `package-lock.json`. لا ترفعي `node_modules` أو `dist`.
2. في GitHub افتحي المستودع ثم **Settings → Pages**.
3. تحت **Build and deployment → Source** اختاري **GitHub Actions**.
4. افتحي **Actions → Deploy to GitHub Pages → Run workflow**، اختاري `main`، ثم اضغطي **Run workflow**. لاحقًا سيعمل النشر تلقائيًا عند كل دفع إلى `main`.
5. انتظري نجاح مرحلتي `build` و`deploy`. سيظهر رابط الموقع في **Settings → Pages** وفي نتيجة النشر.

العنوان المتوقع بعد نجاح النشر: `https://llelanll.github.io/hasnaa-math/`.
إذا كان المستودع خاصًا، يعتمد توفر GitHub Pages على خطة GitHub؛ سيظهر ذلك في صفحة Pages. إذا تغير اسم المستودع أو استُخدم نطاق مخصص، عدّلي `base` في `vite.config.js` وفق المسار الجديد (للنطاق المخصص عادة `/`).

### اختبار نسخة النشر

```sh
npm run build
npm run preview -- --port 4173
TEST_BASE_URL=http://127.0.0.1:4173/hasnaa-math/ npm test
```

خادم Python يجب أن يقدم الموقع تحت مجلد `hasnaa-math` أيضًا؛ تقديم `dist` مباشرة على جذر الخادم لا يطابق إعداد GitHub Pages الجديد.

## نموذج درس أنماط الضرب

افتحي `#multiplication-patterns` أو اختاري «ابدئي الدرس» من صفحة الدروس.
يتضمن أهدافًا وتهيئة بصرية وشرح القيمة المنزلية وثلاثة أمثلة أصلية وأربعة تدريبات متدرجة، ثم اللعبة الحالية ذات عشرة أسئلة واختبارًا مستقلًا من خمسة أسئلة مع تحليل المهارات.
يمنح كل تدريب عشر نقاط مرة واحدة في التقدم المحفوظ، والاختبار عشر نقاط لكل إجابة صحيحة عند التسليم، مع منع تكرار نقاط التسليم. يمكن إعادة الاختبار في محاولة جديدة. النقاط محفوظة محليًا؛ إجابات الدرس وتقدمه ونتائج الاختبارات تبقى بعد إعادة تحميل الصفحة والعودة إلى المتصفح على الجهاز نفسه.
المرجع المفاهيمي: الفصل الثالث، الدرس الأول «أنماط الضرب»، من الكتاب المرفق. الشرح والأمثلة والتدريب والاختبار الجديد مؤلفة للموقع. أسئلة اللعبة القديمة محفوظة دون تغيير.
اختبارات المتصفح تشمل عروض ٣٢٠ و٣٩٠ و١٢٨٠ بكسل، التهيئة والتلميحات والتصحيح والنقاط واللعبة ومراجعة المهارات وإعادة الاختبار، إضافة إلى اختبارات الصفحات واللعبة السابقة.

## الفصل الثالث كاملًا

أضيفت سبعة دروس إلى النموذج السابق، ولكل منها تهيئة وأهداف وشرح أصلي وثلاثة أمثلة محلولة على الأقل، وأربعة تدريبات متدرجة، ولعبة من ثلاث بطاقات، واختبار مستقل من خمسة أسئلة، ومراجعة للمهارات. تُكشف خطوات الأمثلة تدريجيًا.

| الدرس | الرابط داخل الموقع |
| --- | --- |
| أنماط الضرب | `#multiplication-patterns` |
| خاصية التوزيع | `#distributive-property` |
| تقدير نواتج الضرب | `#estimating-products` |
| الضرب في عدد من رقم واحد | `#multiply-one-digit` |
| خطة حل المسألة: رسم صورة | `#draw-a-picture` |
| الضرب في عدد من رقمين | `#multiply-two-digits` |
| خصائص الضرب | `#multiplication-properties` |
| استقصاء حل المسألة: اختيار الخطة المناسبة | `#choose-a-strategy` |

تبقى صفحات الموقع واللعبة السابقة متاحة. ينظم `src/chapter-three-data.js` محتوى الدروس السبعة، ويعرض `src/chapter-three.js` التفاعلات مع حالة مستقلة محفوظة لكل درس. إجابات الاختبار لا تكشف صحتها قبل التسليم. لا تتكرر نقاط التدريب أو تسليم الاختبار نفسه عند التنقل، وتُحتسب نقاط جديدة عند بدء محاولة اختبار أو جولة لعب جديدة.

عند تأليف مسائل جديدة، تُنوّع أسماء الطالبات ضمن: سارة، ريم، ليان، جود، لمى، دانا، هيا، شهد.

اختبارات الفصل تتحقق من التهيئة، وكشف الأمثلة، وتلميحات التدريب ومحاولاته، والتصحيح في الألعاب، وتعديل إجابات الاختبار، ومنع تسليم اختبار ناقص، وتحليل المهارات، وإعادة المحاولة، وعزل حالة الدروس، واحتساب النقاط وبقائها بعد تحديث الصفحة، واتجاه RTL وعدم تجاوز العرض على الجوال والكمبيوتر.

## التقدم وجداول الضرب والشخصيات

- `#chapter-three`: لوحة الفصل الثالث، وعلامات الإكمال، وآخر اختبار وأفضل نتيجة، والتقدم الكلي. يكتمل الدرس عند تسليم اختباره بعد فرصة المراجعة الثانية عند الحاجة.
- `#progress`: لوحة تقدم الطالبة ورصيد النقاط وروابط إتقان الجداول.
- `#multiplication-tables`: جداول ٠–١٠ والتدريب الشامل؛ أوضاع التعلم البصري والتدريب وتحدي السرعة.
- `#table-mastery`: إتقان كل جدول وأفضل نتيجة والنجوم.

تُحفظ بيانات التعلم في `hasnaa-learning-v2` داخل localStorage، مع الإبقاء على رصيد `hasnaa-points` السابق. تُحفظ حالة كل درس ونتيجة آخر اختبار وأفضل نتيجة وعدد المحاولات وحقائق الجداول الصحيحة والخاطئة ومكافآتها. لا توجد حسابات أو خدمات خارجية؛ حذف بيانات المتصفح يحذف التقدم، وإذا منع المتصفح التخزين يعمل النشاط في الذاكرة دون ضمان البقاء بعد الإغلاق.

يبدأ الخطأ بتلميح دون كشف الإجابة، ثم محاولة ثانية، ثم شرح عند استمرار الخطأ. اختبارات الدروس تعيد الأسئلة الخاطئة مرة ثانية قبل عرض النتيجة النهائية.

يشمل تدريب الجدول المفرد جميع عوامله من ×٠ إلى ×١٠ مرة واحدة في الجولة، ويختار التدريب الشامل ٢٢ حقيقة مع ترجيح الحقائق التي سبق الخطأ فيها. تتنوع الأسئلة بين الاختيار والكتابة والعامل الناقص والصح والخطأ. لا يُستخدم سؤال عامل ناقص مع عامل ثابت صفر لأن إجابته غير وحيدة. يبدأ تحدي السرعة عند الضغط على ابدئي ويستمر ٦٠ ثانية، وينتهي بالخروج منه. النتيجة تحسب الإجابات الصحيحة من المحاولة الأولى؛ الإجابة بعد التلميح تبقى فرصة للتعلم.

تمنح حقيقة الجدول ١٠ نقاط مرة واحدة فقط على هذا الجهاز عند الإجابة الصحيحة من المحاولة الأولى، عبر سجل مكافآت مستقل عن ترتيب السؤال ووضع التدريب؛ إعادة الجولة وتحديث الصفحة لا يعيدان المكافأة. تُتقن الحقيقة بعد إجابتين مستقلتين صحيحتين من المحاولة الأولى. الإتقان = الحقائق المتقنة من ١١، والنجوم: واحدة لحقيقة متقنة فأكثر، اثنتان لست حقائق فأكثر، وثلاث لإتقان الحقائق الإحدى عشرة. أفضل نتيجة هي أعلى نسبة صحيحة من المحاولة الأولى في الجولات المكتملة.

جُهزت ٢١ صورة WebP من لوحة الشخصيات المرفقة بعد إزالة عناوينها وتهيئتها؛ مجموعها أقل من ٤٠٠ كيلوبايت. تظهر حسناء في مواقف الترحيب والشرح والتفكير والتطبيق والتشجيع والمساعدة والمحاولة والإنجاز والختام، مع ليان للتلميحات ودانا للإتقان. الصور محلية وتُحمّل عند الحاجة، وتبقى ضمن تدفق الصفحة دون تغطية المحتوى أو الأزرار على الجوال.

تشمل الاختبارات التحقق الحسابي من الحقائق الـ١٢١، وجميع الجداول والأوضاع، وترجيح الأخطاء، ومنع تكرار النقاط، والمؤقت، وحفظ آخر وأفضل نتيجة، واسترجاع التقدم بعد إعادة فتح سياق المتصفح، وتحميل صور الشخصيات ضمن مسار GitHub Pages، إضافة إلى اختبارات الدروس واللعبة السابقة.

## اتجاه المحتوى الرياضي

تظل واجهة الموقع والفقرات العربية RTL. يتولى `src/math-direction.js` عزل التعبيرات الرياضية في `.math-content` باتجاه LTR مع `unicode-bidi: isolate-override`؛ تعيين `direction` وحده لا يكفي للمتتابعات ذات الأرقام العربية والفواصل.

- استعملي `mathHTML(expression)` للتعبير الرياضي المستقل، و`formatMathText(text)` للجمل العربية التي تحتوي تعبيرات رياضية. لا تعكسي مصفوفة الأعداد أو النص، ولا تغيّري الأرقام العربية لمعالجة الاتجاه.
- يمكن تمييز حاوية تحتوي رياضيات محضة بـ`data-math`، وتُضبط عناصر MathML الأصلية كذلك. تبقى الكلمات والجمل العربية خارج حاوية العزل.
- يعالج `isolateMath` المحتوى القديم، ويراقب `observeMath` التغييرات داخل التطبيق، بما فيها الأسئلة والتلميحات والنتائج المضافة ديناميكيًا. المعالجة متكررة بأمان دون إعادة ترتيب النصوص أو تغييرها، ولا تمس المدخلات أو بيانات التقدم أو تنقل الأسهم في الواجهة.
- تشمل الصياغات المغطاة المتتابعات والفواصل، والأقواس والمعادلات والعمليات الحسابية والكسور والإحداثيات والأسهم الرياضية، مع الحفاظ على الترتيب المنطقي المكتوب لكل رمز.

تفحص `tests/math-direction.test.js` المواضع الفعلية لمحارف الأرقام والرموز داخل المتصفح على عروض ٣٢٠ و٣٩٠ و١٢٨٠ بكسل. يثبت اختبار تعطيل العزل أن الفحص يكتشف الانعكاس الأصلي، ثم يتحقق من زواله بعد إعادته. تُراجع أيضًا جميع بيانات أسئلة الفصل الثالث وأمثلته، ومراحل الدروس، والأسئلة العشرة للعبة أنماط الضرب، مع ضمان بقاء النصوص والأرقام العربية كما هي.

يشغّل مسار GitHub Pages اختبارات اتجاه الرياضيات على نسخة الإنتاج قبل رفعها للنشر؛ أي إخفاق يمنع نشر النسخة الجديدة. تُستخدم نسخة Chromium المتوفرة محليًا أو نسخة Playwright المثبتة في بيئة CI.

## دروس الفصل الثالث: التفاعل أولًا

مسار الطالبة: **👀 شوفي → 🧠 جرّبي → 🎮 العبي → ⭐ تحدّي**. داخل «شوفي» تختار المشهد البصري أو التهيئة أو بطاقة الفكرة، وتفتح الأهداف عند الحاجة. تعرض الأمثلة خطوة واحدة مع زري الكشف والرجوع، وتبقى جميع الأمثلة والخطوات متاحة. تعرض النتيجة ملخص المهارات أولًا، ثم مراجعة كل سؤال عند فتح بطاقته.

يقدّم `src/visual-learning.js` ثمانية مشاهد خفيفة مبنية بعناصر HTML وCSS: تغيير القيمة المنزلية، وتفكيك مستطيل، واختيار الأقرب على خط أعداد، وإعادة تجميع الآحاد، وعد الفواصل بين الأعلام، وكشف النواتج الجزئية، وتبديل صفوف النقاط، وترتيب خطوات حل المسألة. تعمل الأنشطة باللمس والضغط ولوحة المفاتيح دون اشتراط السحب أو إضافة مكتبة أو وسائط جديدة. لا تمنح إعادة كشف الخطوات نقاطًا إضافية.

تُحفظ حالة المشاهد والأمثلة في `states['visual:<lesson-slug>']` ضمن مخزن التقدم الحالي. تبقى معرّفات المراحل السابقة وحقول الاختبارات والألعاب والنتائج دون تغيير للتوافق مع التقدم المحفوظ. لا تتغير بيانات الأسئلة أو لعبة أنماط الضرب ذات الأسئلة العشرة أو جداول الضرب.

تفحص `tests/visual-learning.test.js` المشاهد الثمانية، وجميع خطوات الأمثلة الـ٢٥ وبطاقات الفكرة، والمحاولة الثانية، والتفاعل بلوحة المفاتيح، وحفظ المشاهد بعد التحديث، وعدم تكرار النقاط أو تجاوز عرض الشاشة على عروض ٣٢٠ و٣٩٠ و١٢٨٠ بكسل. يُشغّل النشر هذا الاختبار مع اختبارات اتجاه الرياضيات على نسخة الإنتاج قبل السماح بالنشر.

قاعدة إعداد المحتوى لاحقًا: **الطالبة تفعل أكثر مما تقرأ**. لا يُعتمد عدد ثابت من الفقرات أو الأمثلة النصية قالبًا للدروس؛ يُختار التفاعل الملائم للمهارة أولًا. يُقدّم الشرح في مقاطع قصيرة بلا اقتطاع للمعلومة، وتُكشف النواتج الجزئية بالترتيب: الآحاد، ثم العشرات، ثم الجمع بضغط مستقل. تبقى الألعاب والنتائج المحفوظة كما هي.


## بنية المنهج الكامل

`src/curriculum/catalog.js` فهرس خفيف للعناوين والروابط فقط. تُحمّل بيانات كل فصل من `chapters/chapter-N.js` ومحرك الأنشطة عند فتح الدرس، ولا تُجلب عند فتح الرئيسية. يبقى الفصل الثالث على محركه المعتمد وروابطه القديمة. انتقلت صفحة `#lessons` إلى فهرس الفصول الاثني عشر، وأصبحت `#progress` لوحة تقدم المنهج. لا تزال الملاحظات السابقة متاحة على `#multiplication-notes` من قسم الألعاب.

تُحفظ حالات الدروس الجديدة تحت `states['curriculum:<slug>']` داخل مخزن التقدم الحالي، وتُسجّل النتائج بنفس واجهته القديمة. تستخدم مكافآت الأسئلة مفاتيح ثابتة لكل درس ونشاط وسؤال، بما فيها محركات الفصل الثالث، دون تعديل الأرصدة السابقة. تُظهر واجهة الجولة ما اكتُسب فعلًا، مع بقاء الدرجات والنجوم قابلة للتحسين.

لا تُكتب إجابات الكسور كنواتج تقريبية؛ تقارن مدخلات الطالبة كسورًا دقيقة، وتفرض أسئلة أبسط صورة الاختزال. تفحص اختبارات المحتوى مرجعًا حسابيًا مستقلًا، وتراجع مساوات خطوات الحل أيضًا. تضيف اختبارات اتجاه المنهج فحصًا فعليًا لمواضع الأرقام والرموز على الكمبيوتر والجوال.

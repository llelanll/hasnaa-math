# تقرير استكمال منهج رياضيات خامس

اكتملت الفصول الاثنا عشر وفق تسلسل الدروس المعتمد من ملفات الكتاب، مع إبقاء محتوى الفصل الثالث وتصميمه ولعبته ذات الأسئلة العشرة. الحقوق والشخصيتان الجانبيتان وصور الشخصيات المحلية وتصميم الرئيسية محفوظة.

## الحصر

- ٨١ درسًا أساسيًا، ومعمل إثرائي واحد للأعمدة والجداول الإلكترونية؛ المجموع ٨٢ صفحة تعلم.
- ٨٢ نشاط استكشاف، و٨٢ تهيئة قصيرة، و٢٤٧ مثالًا محلولًا قابلًا للكشف خطوة بخطوة، و٣٢٨ تدريبًا، و٨٢ لعبة درس قصيرة.
- مجموع أنشطة التعلم بهذا التعريف: ٨٢١ نشاطًا. تُحسب اللعبة نشاطًا واحدًا، ولا تُضاف أسئلتها مرة ثانية إلى هذا المجموع.
- تضم ألعاب الدروس ٢٥٣ سؤالًا أو بطاقة، وتشمل لعبة أنماط الضرب الأصلية ذات ١٠ أسئلة.
- ٨٢ اختبارًا مستقلًا من خمسة أسئلة؛ المجموع ٤١٠ أسئلة تقييم. المعمل الإثرائي له اختبار منفصل، ولا يزيد عدد دروس المنهج الأساسي عن ٨١.
- تدريب الجداول ٠–١٠ والتدريب الشامل وأوضاعه الثلاثة محفوظة، وهي أنشطة إضافية لا تدخل في حصر الدروس أعلاه.

## جودة التعلم

المسار في الدروس الجديدة: شوفي ← مثال ← جربي ← العبي ← تحدي ← نتيجتي. ظل مسار الفصل الثالث المعتمد كما هو.

تختلف التمثيلات حسب المهارة: المنازل، وشبكات المئة، والمقارنة والترتيب، ومحاذاة الفواصل، والتوزيع، والقسمة المتدرجة، والميزان وآلة الدالة، وشرائط الكسور وأشكال ڤن، والأعمدة والأكياس الاحتمالية، والقواسم والمضاعفات، والمسطرة والساعة، والشبكة الإحداثية وتحويل الأشكال، والمحيط ومربعات المساحة ومكعبات الحجم. يوجد ستة أنماط للألعاب: المطابقة والتصنيف وترتيب الحل وبناء الإجابة ومسار الخيارات واكتشاف الخطأ. لا أصوات أو فيديو أو مكتبات جديدة.

الأمثلة الجديدة تربط المشهد التفاعلي بمعطيات كل مثال، وتكشف خطوة حساب واحدة في كل مرة. عند الخطأ يظهر تلميح، ثم محاولة ثانية، ثم تفسير. في التبسيط لا يُحتسب الكسر غير المختزل جوابًا صحيحًا لسؤال يطلب أبسط صورة، حتى لو كانت قيمته مكافئة. تُقبل الأرقام العربية والكسور المكافئة في الأسئلة التي تسمح بذلك، وتُقارن مدخلات الطالبة العددية ككسور دقيقة بدل قبول قيم قريبة بالخطأ.

## الحفظ والمكافآت

استُخدم مخزن التقدم الحالي دون تغيير مفاتيح النقاط أو حذف الرصيد أو النتائج السابقة. يُحفظ إكمال الدرس وآخر نتيجة وأفضل نتيجة وحالة النشاط. تعرض اللوحة العامة الفصول الاثني عشر، ولكل فصل الدروس المكتملة والنتائج والنجوم.

التعديل التقني الوحيد داخل محركات الفصل الثالث هو إضافة مفاتيح مكافآت ثابتة وإظهار النقاط المكتسبة فعلًا: لا تعيد المحاولة أو إعادة فتح السؤال أو تبديل وضع اللعبة مكافأة السؤال نفسه. تبقى درجات المحاولات والنجوم قابلة للتحسين. لم تتغير أسئلة الفصل الثالث أو أمثلته أو صور الشخصيات أو لعبة أنماط الضرب.

## التحقق والأداء

اجتازت الجولة الشاملة ٥٤ اختبارًا دون إخفاق؛ وتعيد بوابة النشر تشغيل المجموعة كاملة على نسخة الإنتاج قبل رفع الموقع.

- اختبار مستقل لإجابات ١١٨٤ مجموعة بيانات تعليمية جديدة، بما فيها المعمل الإثرائي، وفحص ٧٣٣ مساواة رقمية في خطوات الحل.
- فحص ترتيب المحارف الفعلي لـ١٨٢٥ تعبيرًا رياضيًا على عروض ٣٢٠ و٣٩٠ و١٢٨٠ بكسل، مع بقاء النص والأرقام كما كُتبت. وُسّع العزل الحالي لحالة مربع المقارنة الفارغ دون عكس السلاسل.
- فحوص لمسارات الدروس الجديدة كلها على الكمبيوتر والجوال، تشمل التمارين والألعاب والاختبارات وحفظ النتائج وإعادة المحاولة وحماية المكافآت. فحوص أعمق للمختبر والكسور والساعة والشبكة والمكعبات على ثلاثة مقاسات.
- فحوص لجميع الفهارس وروابط التنقل والحقوق والشخصيتين، ومقارنة بصمات المحتوى والصور والتصميم المعتمد لمنع حذفها أو تغييرها عرضيًا.
- بيانات الفصول الجديدة ومحرك أنشطتها محملة عند الطلب عبر تقسيم الكود. لا تُحمّل أسئلتها عند فتح الرئيسية. بُنيت الفصول ضمن مسار /hasnaa-math/.
- تُشغّل الاختبارات الشاملة في GitHub Actions قبل السماح بنشر GitHub Pages.

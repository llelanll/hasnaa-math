# Google Analytics 4

معرّف القياس: `G-7X1EY281MD`.

الموقع تطبيق JavaScript بمدخل HTML واحد ومسارات `#`. يستدعي `src/main.js` الدالة `trackPage(page)` بعد العرض، وتنفذ `src/analytics.js` القياس فقط في نسخة الإنتاج على `https://llelanll.github.io/hasnaa-math/`. لا تُرسل زيارات من التطوير أو معاينة localhost أو اختبارات الموقع المعتادة.

## الزيارة الأولى والتنقل

- يُحمّل ملف Google tag الرسمي `https://www.googletagmanager.com/gtag/js?id=G-7X1EY281MD` بصورة غير متزامنة مرة واحدة في المستند.
- تُنشأ قائمة `dataLayer` ودالة `gtag`، ثم أمر `js` وتهيئة `config` واحدة مع `send_page_view: false`.
- تُرسل زيارة يدوية واحدة للمسار الأول الفعلي، بما فيه الرابط المباشر لدرس أو قسم نافس، ثم زيارة واحدة لكل تغير للمسار المعتمد.
- لا تُعد إعادة العرض أو الإجابة أو التلميح أو السؤال التالي أو تحديث النقاط تنقلًا. الانتقال من قسم أ إلى ب ثم العودة إلى أ يسجل ثلاث زيارات؛ تحديث المستند يبدأ زيارة جديدة واحدة.
- لا يضيف القياس مستمع تنقل موازيًا، ولا يغيّر `history` أو الروابط أو عنوان الصفحة المرئي.

## إعداد مصدر البيانات الضروري

يجب إبقاء **Enhanced measurement / القياس المحسّن معطلًا بالكامل** لمصدر الويب الذي يحمل هذا المعرّف. أكدت صاحبة الموقع تعطيله وحفظ الإعداد أثناء التنفيذ. ينطبق ذلك خصوصًا على القياس التلقائي لتغيرات سجل المتصفح وتفاعلات النماذج. هذا إعداد في حساب Analytics، ولا يغيره كود الموقع.

توضح [وثائق Google لقياس الزيارات](https://developers.google.com/analytics/devguides/collection/ga4/views) أن `send_page_view: false` يعطّل الزيارة التلقائية للتهيئة، لكنه لا يعطّل بمفرده الزيارات التي ينشئها القياس المحسّن عند تغير السجل. راجعي أيضًا [إعدادات القياس المحسّن الرسمية](https://support.google.com/analytics/answer/9216061?hl=ar). إعادة تشغيل هذه الخاصية قد تعيد التسجيل المزدوج أو تضيف أحداثًا تلقائية للنماذج.

## البيانات والتقارير

يرسل كود الربط المحلي في حدث `page_view` المعاملات التالية؛ قد تضيف Google حقولها التقنية المعتادة:

| المعامل | القيمة |
|---|---|
| `send_to` | معرّف القياس المحدد |
| `page_title` | عنوان عربي ثابت من بيانات الفهرس أو قائمة مسارات نافس العامة |
| `page_location` | رابط الموقع الأساسي مع مسار `#` معتمد فقط |
| `page_referrer` | رابط القسم السابق المعتمد داخل الموقع، وفارغ عند الدخول الأول |

لا يقرأ كود الربط المحلي نصوص DOM أو النماذج أو الإجابات أو النتائج أو النقاط أو `localStorage`، ولا يرسل معرّفات الطالبات أو خصائص مستخدمات أو أحداثًا للإجابات. لا يمرر الاستعلامات أو الأجزاء غير المعتمدة من الرابط أو المرجع الخارجي؛ ويُحمّل ملف Google tag بسياسة `no-referrer`. تُعطل Google signals وإشارات تخصيص الإعلانات، وتُرفض أذونات تخزين الإعلانات وبيانات مستخدم الإعلانات وتخصيص الإعلانات.

تبقى آليات Analytics التقنية المعتادة، مثل الجلسات وأول زيارة والتفاعل وملفات الارتباط التحليلية الخاصة به، جزءًا من Google tag؛ لا يربطها الموقع بهوية الطالبة أو سجل تعلمها. يُحدَّث سياق الصفحة الآمن عالميًا قبل التهيئة وعند التنقل، مع تمريره صراحة في حدث الزيارة.

في تقرير **التفاعل ← الصفحات والشاشات** اختاري بُعد **عنوان الصفحة** لتمييز الفصول والدروس والتدريب المتنوع والمحاكاة. تحمل `page_location` روابط `#` الفعلية أيضًا، لكن تقرير مسار الصفحة المعتاد قد يجمع الأجزاء التي تشترك في المسار الأساسي؛ لذلك لا تُنشأ روابط افتراضية غير موجودة في الموقع.

## التحقق

تختبر `tests/analytics.test.js` المعرّف والتحميل والتهيئة مرة واحدة، والزيارة الأولى والتنقل والرجوع وعدم تكرار أحداث إعادة العرض، والبيانات المسموح بها، والعمل عند حجب الوسم. تستخدم اختبارات المتصفح نسخة الإنتاج المحلية تحت أصل نشر محاكى، مع اعتراض ملف Google tag، حتى لا ترسل الاختبارات أي زيارات حقيقية إلى الحساب.

تبقى اختبارات الموقع السابقة دون تغيير، وتعيد بوابة GitHub Pages تشغيل المجموعة كاملة قبل النشر. نجاح الاختبارات يثبت سلوك التكامل محليًا، ولا يحل محل فحص التقارير الفعلية في حساب Analytics.
